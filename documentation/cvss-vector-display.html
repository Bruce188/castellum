CVSS Vector Display

CvssVectorBreakdown component: full-word metric grid as primary display, raw vector as secondary reference, graceful degradation for malformed and absent vectors.

Section: Frontend UI · Added: V26 / PR #66

The CvssVectorBreakdown component renders CVSS v3.1 base vectors in a human-readable metric/value grid. Full English words are the primary display; the raw vector string is demoted to a clearly-labelled secondary reference.

Overview

Before PR #66, the component displayed only the raw CVSS:3.1/AV:N/... string in a monospace block. Operators had to mentally decode the abbreviations to understand the risk profile of a vulnerability.

PR #66 promotes the decoded metric grid — already computed by frontend/src/lib/cvss.ts — to the primary display, and moves the raw string to a smaller, labelled "Raw vector" reference below the grid.

Metric/value mapping

The component decodes the eight CVSS v3.1 base metrics in fixed output order using a static label map in frontend/src/lib/cvss.ts. No third-party scoring library is used.

Abbreviation Full metric name Possible values (abbrev → label)
AV Attack Vector N → Network, A → Adjacent, L → Local, P → Physical
AC Attack Complexity L → Low, H → High
PR Privileges Required N → None, L → Low, H → High
UI User Interaction N → None, R → Required
S Scope U → Unchanged, C → Changed
C Confidentiality N → None, L → Low, H → High
I Integrity N → None, L → Low, H → High
A Availability N → None, L → Low, H → High

The decoded grid is rendered as a <dl> with two columns: metric name on the left (<dt>, muted) and full-word value on the right (<dd>, bold). No bare single-letter abbreviations appear as standalone primary values.

Severity band

When a numeric score is supplied via the score prop, the component renders a Severity: <band> badge above the metric grid. The band is derived from the CVSS v3.1 severity rating scale:

Score range Band
≤ 0.0 None
> 0.0 – < 4.0 Low
4.0 – < 7.0 Medium
7.0 – < 9.0 High
9.0 – 10.0 Critical

The badge element carries data-testid="cvss-severity-band". It is absent when no score is supplied.

Secondary raw-vector reference

Below the metric grid the raw CVSS:3.1/AV:... string is rendered in a smaller monospace span, introduced by the plain-text caption "Raw vector". The container carries data-testid="cvss-raw-vector".

<div data-testid="cvss-raw-vector" className="mt-2 text-gray-400">
  <span className="text-xs mr-1">Raw vector</span>
  <span className="font-mono text-xs break-all">{vector}</span>
</div>

This satisfies two requirements:

  • Operators who need to paste the vector into an external tool can copy it directly from the "Raw vector" field.
  • Automated tests that verify the raw string is present can target data-testid="cvss-raw-vector" without brittle text matching.

Graceful degradation

The component handles three failure modes without crashing:

Input Render output
Valid CVSS:3.1/... string Full metric grid + Raw vector reference
Malformed string (no CVSS:3.1/ prefix, incomplete tokens, unknown value abbreviations) Raw string rendered as-is in monospace; no metric labels shown
null, undefined, or empty string Em-dash (—) rendered; no metric labels, no raw-vector block

The parser (parseCvssV31Vector) returns null for any input that does not start with the CVSS:3.1/ prefix or that contains a missing/unknown metric value. The component checks for null before rendering the grid path.

[NOTE] Only CVSS v3.1 base metrics are decoded. Temporal and environmental metrics are not parsed. CVSS v2 and v3.0 vectors are treated as malformed and fall back to the raw-string display.

The component accepts two props:

interface Props {
  vector: string | null | undefined;   // raw CVSS vector string
  score?:  string | null;              // numeric score as string (e.g. "7.8")
}

Usage example

// Renders full metric grid + severity band + raw vector reference
<CvssVectorBreakdown
  vector="CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H"
  score="7.5"
/>

// Renders metric grid + raw vector reference, no severity band
<CvssVectorBreakdown
  vector="CVSS:3.1/AV:L/AC:H/PR:L/UI:R/S:U/C:H/I:H/A:H"
/>

// Renders em-dash (absent vector)
<CvssVectorBreakdown vector={null} />
